# Tessera | 3D Creation Software Landing Page

A modern, interactive landing page for **Tessera**, a fictional free and open-source 3D creation application. Designed with a clean aesthetic, smooth animations, and an interactive 3D robotic arm to showcase the concept of a professional 3D modeling and animation tool.

## Features

- Modern and responsive design for desktop, tablet, and mobile devices
- Interactive 3D robotic arm rendered using Three.js
- Cursor-controlled 3D interaction with live joint angle indicators
- Light and dark theme toggle
- Dynamic operating system detection (Windows, macOS, Linux)
- Interactive subdivision modeling demonstration with an adjustable slider
- Tab-based workflow section showcasing different production stages
- Animated Python code example
- Download section with dedicated options for different operating systems
- FAQ section with expandable answers
- Smooth animations and interactive UI elements

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Three.js
- Google Fonts (Sora, DM Sans, JetBrains Mono)

## Project Structure

```text
├── index.html

```

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/tessera.git
   ```

2. Open the project folder.

3. Launch `index.html` in your browser.

No build tools or installation required.

## Customization

| What to Change | Where |
|---|---|
| Page content and sections | `index.html` |
| Layout, colors, and responsive styling | `style.css` |
| Animations and interactive functionality | `script.js` |
| 3D scene and robotic arm | `script.js` (Three.js) |

## Note

Tessera is a fictional software concept created for design and front-end development purposes. The download buttons are demonstrative and do not provide actual software downloads.
